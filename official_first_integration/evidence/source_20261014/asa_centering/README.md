# ASA 居中偏好，2026-10-14

用户报告上楼路线切内角、腿部被栏杆卡住。原 ASA 搜索仅计算纵向/横向移动与转向代价，string pulling 仅最小化三维长度；通过静态机身检查并不代表具有腿部动态摆动余量。

本次增加 **软距离代价**，不改变地图、机身轮廓、运动校验、定位、步态或局部规划控制参数：

- 从已有可通行 cell 提取外边界；可跨越高度差内的邻接踏板相连，内部 polygon/yaw/tile 接缝不算障碍，不将上下重叠楼层投影合并。
- 优先争取距可通行**机器人中心区域**边界 0.30 m 的额外余量。边界附近平方惩罚，权重 3；窄通道仍由原有运动检查决定可通行性，没有新增硬膨胀门槛。
- 两次 A*、反向启发式、最终候选比较使用同一加权代价；移动边按最多 0.10 m 间距积分，原地转向也倾向宽敞位置。各 yaw 层共用空间边计算，静态图只在启动时预计算。
- String pulling 同时考虑长度和边界惩罚，并保留原有 portal、支撑、朝向和最终运动证书，避免重新拉回内角。楼梯导航属性按最终路径重新标注。

本机和导航机均通过 22 项测试：新增转角居中、踏板接缝、重叠楼层、边内部/原地转向惩罚、优化梯度检查，保留窄通道、上下楼、跨层隔离、搜索和缓存回归。
