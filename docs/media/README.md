# Demo assets / 演示素材

The complete September 30, 2026 screen recording is preserved as `demo-full.mp4` (H.264, 3:55.9, about 12.8 MB). It is transcoded from the supplied WebM without temporal cuts. GitHub READMEs display `demo-preview.gif` directly and link to the full MP4; no external video account is required.

The preview concatenates 12–20 s and 104–112 s at original speed. `demo-frame.png` is from 20 s; `stairs-frame.png` is from 105 s. The source digest and transformation metadata are in [provenance.json](provenance.json).
